## مثال Keras

```python
import keras
model = keras.Sequential([keras.Input((16,16,1)),
    keras.layers.Conv2D(4,3,padding="same",activation="relu"),
    keras.layers.MaxPooling2D(2),
    keras.layers.Conv2D(8,3,padding="same",activation="relu"),
    keras.layers.MaxPooling2D(2), keras.layers.Flatten(),
    keras.layers.Dense(16,activation="relu"), keras.layers.Dense(4)])
```

يمتلك النموذج المجمّع هدفاً لكنه لا يتعلم قبل خطوات المحسن.

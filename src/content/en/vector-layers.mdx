## How it works

A layer usually outputs many values at once. Each output unit uses its own weights but reads the preceding representation. Matrix multiplication groups these neuron calculations. Later layers receive activations, not the original pixels directly, unless a skip connection explicitly supplies them. The whole model is a composition of vector functions.

## Worked example

A dense layer maps 128 features to 16 activations with a 128×16 weight matrix and 16 biases.

## Common misconception

A hidden layer does not add a new training label for every neuron. Its features are shaped by the final objective.

## How it works

A prediction is what the current model outputs; a target is the value supplied by the dataset. Loss measures disagreement in a way that gives a learning signal. The training objective usually averages losses across samples, possibly adding regularization. A metric describes performance but need not be differentiable or serve as the optimized loss.

## Worked example

For prediction 3 and target 1, squared error is (3−1)²=4. Prediction 1.5 gives 0.25.

## Common misconception

Accuracy alone supplies no useful gradient through an argmax decision.

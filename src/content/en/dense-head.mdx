## How it works

After flattening, each dense output reads every feature with its own weight. Spatial identity is implicit in the vector index, so different positions can get different weights. A dense head can learn useful combinations but can also become large and position-sensitive. Bias adds one parameter per output unit.

## Worked example

128 flattened features into 16 units require 2,048 weights plus 16 biases. Selecting one feature reveals 16 outgoing connections.

## Common misconception

The flattened values are activations, not automatically weights or probabilities.

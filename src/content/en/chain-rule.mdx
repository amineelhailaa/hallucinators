## How it works

A derivative measures local sensitivity. A gradient collects derivatives with respect to all parameters. Backpropagation applies the chain rule from the loss through the computational graph, reusing intermediate results. Shared weights accumulate contributions from every place they are used. Backpropagation calculates gradients; it does not itself choose an update rule.

## Worked example

x=2,w=0.5,b=0,target=3 gives z=1 and L=(1−3)²=4. dL/dz=−4, dz/dw=2, so dL/dw=−8.

## Common misconception

Gradients describe local changes. A very large step need not reduce loss.

## Keras example

```python
import keras
import tensorflow as tf
with tf.GradientTape() as tape:
    prediction = model(x, training=True)
    loss = tf.reduce_mean((prediction - y) ** 2)
gradients = tape.gradient(loss, model.trainable_variables)
```

## How it works

A tensor is a multidimensional array. Shape names the size of each axis; dtype names how each value is represented. We use channels-last ordering: batch, height, width, channels. The batch axis separates independent examples; convolution must not mix neighboring samples. A float32 value uses four bytes.

## Worked example

A batch [32,16,16,1] has 8,192 values, requiring 32,768 bytes in float32 before intermediate activations.

## Common misconception

Reshape does not resize an image. It only reinterprets the same number of values.

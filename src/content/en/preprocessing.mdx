## How it works

Decode bytes into pixels, choose the color order, resize with a documented aspect-ratio policy, and normalize once. Stretching changes geometry; letterboxing preserves geometry but adds borders. Fit learned normalization statistics only on training data. The identical pipeline must run during inference or the model receives a different distribution.

## Worked example

An intensity of 128 becomes 0.502. Dividing this result by 255 again gives 0.00197, a very different input.

## Common misconception

Data augmentation is not a replacement for consistent preprocessing. Random augmentation is normally disabled for inference.

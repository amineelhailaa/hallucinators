## How it works

The mean batch gradient combines the influence of several samples. Conflicting examples can cancel components. Shuffling changes which examples interact in each update; shuffle inputs and labels together. Larger batches often reduce sampling noise but provide fewer updates per epoch. Our worker uses a seeded shuffle so the sample order can be reproduced.

## Worked example

Gradients [2,−1] and [−2,3] average to [0,1]. This batch changes the second weight but not the first under SGD.

## Common misconception

Do not compare batch sizes using epochs alone without acknowledging different update counts.

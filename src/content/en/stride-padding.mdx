## How it works

Stride sets the distance between sampled patch origins. Padding adds values around the image so edge positions can participate. Dilation spaces kernel elements farther apart without adding weights. “Same” padding gives ceil(input/stride), not always the original size. Invalid configurations should be rejected rather than displayed with impossible shapes.

## Worked example

Input 7, kernel 3, stride 2, no padding gives floor((7−3)/2)+1=3. Same padding gives ceil(7/2)=4.

## Common misconception

Padding changes boundary behavior. It does not guarantee complete translation invariance.

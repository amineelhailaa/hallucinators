## How it works

A sample is one labeled example. A batch groups samples for one gradient calculation and optimizer update. An epoch is one pass through the training dataset. Iterations count updates, not examples. The last batch can be smaller unless explicitly dropped. Batch size changes the number and noise of updates, not the network’s parameter count.

## Worked example

100 samples with batch size 32 give batches 32,32,32,4: four updates per epoch and 12 over three epochs.

## Common misconception

An epoch is not one weight update unless the full dataset is one batch.

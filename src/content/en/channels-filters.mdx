## How it works

Each convolution filter spans all input channels and produces one output channel. It sums channel contributions before adding a bias. Multiple filters can respond differently to the same patch. Deep-learning libraries commonly call cross-correlation “convolution”: the kernel is not flipped during the scan. Learned kernels can accommodate this convention.

## Worked example

Eight 3×3 filters receiving four channels have (3×3×4+1)×8=296 parameters.

## Common misconception

A 3×3 RGB filter is not only nine weights. It has 27 weights because it spans three channels.

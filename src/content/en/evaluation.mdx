## How it works

A confusion matrix counts actual labels against predictions. Precision asks how many predicted positives are correct; recall asks how many actual positives were found. F1 combines them. Report per-class support and macro averages when imbalance matters. Regression uses residuals, MAE and RMSE, not classification accuracy. Keep evaluation independent of model selection.

## Worked example

TP=8, FP=2, FN=4 gives precision=0.8, recall=0.667, F1≈0.727. Predicting the majority class can still have high accuracy.

## Common misconception

One aggregate score can hide a failing minority class. Always inspect class-level errors.

## How it works

Global average pooling computes one average per channel. It reduces a spatial map to its channel count and discards within-channel position information. Flatten preserves all values in a known order. Neither operation has trainable weights. The choice changes the prediction head’s size and what distinctions remain available.

## Worked example

A 4×4×8 map becomes 128 features with Flatten, but only 8 with global average pooling. Dense(16) then has 2,064 versus 144 parameters.

## Common misconception

Averaging is unsuitable when the discarded position is itself the target, unless other features encode it.

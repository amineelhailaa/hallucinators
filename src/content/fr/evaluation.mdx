## Fonctionnement

La matrice compte classes réelles et prédites. La précision mesure les positifs prédits corrects ; le rappel les positifs retrouvés. F1 les combine. Donnez effectifs et moyennes macro en cas de déséquilibre. Pour la régression : résidus, MAE et RMSE. Séparez évaluation et sélection.

## Exemple calculé

TP=8, FP=2, FN=4 : précision=0,8, rappel=0,667, F1≈0,727. La majorité seule peut donner une forte exactitude.

## Équation

## Symboles

TP : vrais positifs ; FP : faux positifs ; FN : faux négatifs ; P : précision ; R : rappel. Définissez les divisions par zéro.

## Fonctionnement

Un tenseur est un tableau multidimensionnel. La forme donne la taille des axes ; le type décrit les valeurs. Nous utilisons lot, hauteur, largeur, canaux. Le lot sépare les exemples indépendants : la convolution ne mélange pas les images. Un float32 occupe quatre octets.

## Exemple calculé

Le lot [32,16,16,1] contient 8 192 valeurs : 32 768 octets en float32 avant les activations intermédiaires.

## Idée reçue

Reshape ne redimensionne pas l’image ; il réorganise le même nombre de valeurs.

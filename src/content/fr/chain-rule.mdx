## Fonctionnement

Une dérivée mesure la sensibilité locale. Le gradient regroupe les dérivées des paramètres. La rétropropagation applique la chaîne dans le graphe et réutilise les résultats. Un poids partagé accumule les contributions de tous ses usages. Le calcul du gradient ne choisit pas la mise à jour.

## Exemple calculé

x=2,w=0,5,b=0,cible=3 donnent z=1 et L=4. dL/dz=−4 et dz/dw=2, donc dL/dw=−8.

## Idée reçue

Le gradient décrit un changement local ; un grand pas peut augmenter la perte.

L : perte ; a : activation ; z : préactivation ; w : paramètre.

## Exemple Keras

import keras
import tensorflow as tf
with tf.GradientTape() as tape:
    prediction = model(x, training=True)
    loss = tf.reduce_mean((prediction - y) ** 2)
gradients = tape.gradient(loss, model.trainable_variables)
